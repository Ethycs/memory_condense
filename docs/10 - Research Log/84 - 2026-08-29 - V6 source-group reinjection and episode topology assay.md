## What was built

V6 is a reusable local evidence plane layered after an authenticated semantic
selection. Its runtime input is only the dated question/typed operator,
immutable semantic index and source histories, exact selected R/P bindings,
and the terminal G allocation. It does not accept a reference answer, outcome,
ordinal route, known source ID, or provider completion.

The primitive:

1. authenticates the complete retained-source G allocation;
2. reverse-maps each selected R/P handle through source, cell, segment, and
   local span, retaining exact receipts;
3. ranks user/action/date/numeric/factual assertions within selected sources;
4. protects question-derived typed, entity, date, numeric, role, and selected-
   group obligations;
5. adds bounded source-local and optional fixed-interval episode neighbors;
6. selects before exact deduplication, then closes every duplicate to its
   provider-visible R/P owner;
7. packs novel L rows under an independent non-borrowable token cap with
   oversized-row skip-and-continue; and
8. emits an explicit local frontier without claiming global support closure.

The exact R7 adapter reuses the sealed query-population, store, vector, cache,
window-index, semantic-index, protected-evidence, terminal-prompt, and G-map
loaders. It rebuilds one namespace at a time and never serializes a second
semantic index. The V6 result reports zero provider calls and zero retained
transformer-token state.

R7 protected bindings can carry a G handle allocated in an earlier evidence
plane. V6 therefore preserves the original binding receipt while separately
authenticating its terminal R7 G allocation. A focused rebase test rejects an
unannounced mismatch and accepts only an explicit terminal mapping whose
source agrees with the immutable binding.

## Architectural conclusion

V6 establishes a sound, composable provenance and neighborhood primitive, but
raw union ranking is not yet the terminal evidence-plane compiler. The next
integration layer should compile one bounded provider payload from R, P, and L
with explicit per-plane and per-obligation reservations. In particular, each
directly anchored episode needs a protected best user assertion before generic
assistant context competes for the remaining budget. Deduplication must remain
post-selection and preserve exact R/P owner closure; open packing and global
set/count frontiers must continue to route to V7 rather than imply closure.

## V6.1 stratified local lanes

The negative q82 control isolated two separate compiler defects. First, broad
lexical scoring could fill a direct episode's four admission slots with a
generic question or assistant advice even when that same authenticated episode
contained an exact user assertion. Second, when a protected selected handle was
itself the best factual row in an episode, the next novel factual row became a
lane tail. Post-selection dedup then exposed the protected owner correctly, but
the novel row arrived only after unrelated lanes had spent the L budget.

V6.1 repairs the generic ordering contract without adding an ordinal, target,
gold, source-ID, or provider rule:

- source-neighbor, direct-episode, adjacent-episode, source-group, and mandatory
  coverage candidates remain independently identified before union;
- directly anchored episodes rank user factual assertions, matching actions,
  dated assertions, and numeric assertions ahead of contextual text;
- authenticated episode-seed and per-lane insertion order is preserved, and
  lane tails advance round-robin instead of being globally re-sorted;
- every factual direct-episode candidate receives an independent assertion
  head, so a protected anchor remains selected before dedup but cannot hide a
  second novel user assertion in the same episode; and
- the final deterministic interleave still uses skip-and-continue under the
  unchanged, independent 1,200-token L cap.

The frozen mechanism identifier is
`source_group_episode_neighbor_reinjection_v1_1`; the packing identifier is
`stratified-direct-assertion-lanes-post-dedup-skip-continue-v3`; and the exact
default policy receipt is
`c15f430054445dc96c246a3ba156710a6990b807c07dea571f042104a52795df`.
