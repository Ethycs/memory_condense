## What V7 adds

V7 is the independent G evidence plane after protected R/P retrieval and V6.1
source/episode-local reinjection. It searches the complete immutable semantic
residual index rather than reranking only the rows that earlier planes packed.
The runtime route is question-only: it accepts the dated question, typed
operator, sealed query vectors, unresolved frontier, and exact earlier-plane
bindings. It does not accept a question ordinal, reference answer, target
source, prior outcome, or judge result.

Four cumulative lanes select before any EM/protected-evidence deduplication:

1. dense query-vector similarity;
2. sparse typed-slot, entity, and action support;
3. user-role, numeric, and temporal support; and
4. source/date diversity.

Each lane has an independent segment and token budget with its own receipt.
All selected rows then enter exact protected-owner closure and independent G
packing. Oversized rows are skipped without terminating packing. Every result
retains exact G-to-cell-to-segment/local-span provenance, selected-before-dedup
receipts, owner reinjection, operand/slot closure, and an explicit unresolved
frontier. A low score has no pruning authority. Best-first expansion can prune
only a proof-definite structural contradiction; every unexpanded branch stays
unresolved.

The frozen default policy receipt is
`504cab6a3d145442e7ebc9d1efa71ac9673249c01092e40cec5f00837157bb61`.
Its priority algorithm is
`best-first-four-lane+joint-date-role-completed-or-proposed-action-witness-v3`.
The non-borrowable G payload cap is 4,200 tokens, inside the intended
3,600--4,800-token band.

## Hydrated-quote semantic overlay

The real-store miss audit exposed three generic positive witness seams:

- first-person `brought [object/pronoun] home` denotes a completed acquisition;
- replacement/maintenance language links to service, while planned service is
  admitted only when the question-only operator has `include_proposed=true`
  and the exact quote has a scoped first-person planning cue; and
- an inline `M/D` mention can be year-anchored to the immutable row timestamp,
  while first-person `took [person] to [venue]` denotes a completed visit.

Every witness additionally requires the compiled target date interval,
required user role, and intersection with a query action. Its presence affects
priority only. Absence cannot prune a branch, close an operand, or prove an
answer absent.

The first implementation placed compact-date parsing and new action aliases in
the shared question-neutral index. The exact construction correctly rejected
that change as an R7 lifecycle mismatch before publishing an artifact. The
final design restores the authenticated base index and applies the additions
only after an exact segment is hydrated:

- `linked_action_concepts(text)` adds conservative action bridges without
  changing `canonical_action_concepts` or R7 index receipts;
- `completed_action_concepts(text)` uses exact surface tense, so a proposal
  such as `might visit` cannot inherit completion from the stem of `visited`;
- `planned_action_concepts(text)` scopes explicit first-person proposal cues to
  their containing clause; and
- `linked_event_dates(quote, created_at, existing_event_dates)` overlays valid
  compact month/day dates while leaving the base event-date inventory intact.

This boundary is now covered by adversarial positives and near-misses, as well
as the exact lifecycle canary.

plan opened for measurement. This audit is posthoc, target-labelled,
non-production, and forbidden as a runtime router or scoring feature. It joins
source targets to already sealed V7 candidates; it did not change construction
or replay bytes.

The audit uses overlapping source-level codes:

- **P**: at least one candidate from the target source was packed novel in G;
- **D**: at least one selected candidate was an exact duplicate of an earlier
  protected R/P/L binding and closed to that provider-visible owner;
- **B**: at least one lane selected a candidate before deduplication, but the

- **N**: the source was hydrated, but no candidate from it was selected by a G
